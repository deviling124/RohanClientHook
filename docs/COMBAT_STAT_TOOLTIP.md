# Item tooltip lines for the combat stats

Static analysis of `rohanclient_unpacked.exe`; **not yet seen in game**. Code: `src/ItemTooltip/CombatStatLines.cpp`, table generated by
`tools/gen_tooltip_variants.py`.

The item tooltip builders print one line per item attribute with a `switch (type - 21)` of 0x9B entries; every type above 175 goes to
the "nothing" target. Type 175 is the only one that prints a combat line (`PVP Defense : + n%`, text 6459, format `0xC4A830`).
Three builders have the same shape (`0x69DB90`, the one around `0x8A9025`, the one around `0x8B0025`); each one's `ja` at
`0x69DC04 / 0x8A9034 / 0x8B0034` is replaced by a jump to a dispatcher. The dispatcher compares `eax` (= type - 21) with the new types and
runs a copy of that builder's own type 175 block (relative calls re-based, `push 0xAF` and `push 0x193B` replaced by the type and the
text id), then continues after the shared join call. Other types go to the old target.

| Attribute (item bin) | Stat | Text id | Text |
| --- | --- | --- | --- |
| 181 | PvP Attack | 6461 | `PVP Attack :` |
| 204 | PvP Defense | 6459 | `PVP Defense :` |
| 182 | PvE Attack | 6462 | `PVE Attack :` |
| 203, 176 | PvE Defense | 6460 | `PVE Defense :` |
| 183 | Skill Damage | 6464 | `Skill Damage :` (added by `tools/add_combat_stat_items.py` in the map server repo) |
| 179 | Skill Defense | 200061 | `Skill Defense :` |

If the client bytes at the patch sites differ from the reference build, nothing is patched (the hook still loads).
The not-patched builders (`0x6A0BD6`, `0x6A24B4`, `0x6A639D`, `0x6AB766` families) have another shape; if a tooltip place still shows no
line, it uses one of them.

## Per-item options (tested in game)
Stats given to one item through the database (`TEventItem.attr`, 14 slots of type byte + int16 value) are options, not bin attributes, and are printed by other
code: two line formatters (`0x69E740`, `0x8ABA40`, `__thiscall(type, x, value, color)`, a switch over `type - 1`) fed by loops over the types 1..98, and a few
builders that walk a list or loop with their own counter. `CombatStatLines.cpp` widens those loops to 176..204 and sends our types to the game's own "label +value%"
code. The `ja` of each switch stays a conditional `0F 87` jump (an early version made it unconditional, which sent every option to the dispatcher and hid the old stats).
`novaclient_tooltip.log` records what was patched; the formatter and add-line detours that wrote the per-line trace are diagnostics and can be removed.
